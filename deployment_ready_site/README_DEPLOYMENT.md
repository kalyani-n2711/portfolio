# Deployment Ready Site — Kalyani Agarwal Portfolio

This folder contains all pre-built, production-ready static assets needed for instant deployment on any hosting platform:
- Netlify (`https://app.netlify.com/drop`)
- GitHub Pages
- Vercel
- Render / Surge / Cloudflare Pages

## Included Assets & Structure:
- `index.html` — Main HTML document
- `404.html` — SPA routing fallback
- `_redirects` — Netlify client-side routing redirect rule
- `.nojekyll` — Bypasses Jekyll processor on GitHub Pages
- `assets/` — Minified JS bundle (`index-*.js`) and CSS stylesheet (`index-*.css`)
- Image & PDF Documents:
  - `kalyani_prof_image.jpeg` — Profile photo
  - `yourphoto.jpg` — Fallback image
  - All research papers and certificate PDFs

## How to Deploy via Netlify Drop:
1. Open [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop this entire `deployment_ready_site` folder onto the page.
3. Your site will instantly go live!
